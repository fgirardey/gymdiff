# Docs (Obsidian vault)

- English only. One note per feature, decision or workflow; link with `[[wikilinks]]` (note title, no path, no extension). New notes are linked from `docs/Home.md`.
- New notes start from `docs/_templates/` (`Feature.md`, `ADR.md`).
- Accepted ADRs are never edited: write a new ADR that supersedes the old one.
